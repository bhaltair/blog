## 引用类型
1. object
2. Array
3. Date
4. RegExp
5. Function
6. 包装类型
  > 为了便于操作基本类型值，引入3个特殊的引用类型，在读取一个基本类型值的时候，会自动创建一个基本包装类型的对象

  * Boolean
  * Number
  * String

  > 引用类型与基本包装类型的主要区别就是对象的生存期，自动创建的基本包装类型的对象，只存在于代码执行瞬间，不能为其添加属性和方法
7. 单体内置对象
