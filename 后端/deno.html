  • deno

deno

介绍

  • 一个安全高效的 JS/TS 运行时环境
  • 版本：5.13日发布1.0
  • 构建在 V8 引擎、Rust 语言和 Tokio 之上
  • 目标是为现代程序员提供一个高效、安全的脚本环境

改进

  • **去中心化的包管理机制：**将用户从 npm 中解放出来，同时相比过时的 CommonJS，ECMAScript 模块令人心旷神怡
    • 不再有 node_modules 目录
  • 内置工具
    • 意味着用户无需浪费时间寻找第三方支持；
  • 使用 Web 标准
    • Deno 的 API 未来可期。这给了开发人员信心，让他们知道自己不会浪费时间去学习很快就会过时的东西；
  • 内置 TypeScript 支持
  • 使用 ECMAScript 模块
    • 而不是什么CommonJS
