## concurrently
https://github.com/kimmobrunfeldt/concurrently

package.json 的 script 中并发运行多个命令，例如 gulp 命令和 tsc 命令

```js
{
  "scripts": {
    "watch": "concurrently \"gulp --watch\" \"tsc --watch\""
  }
}
```

## prompts

命令行对话框

```js
const prompts = require('prompts');

let questions = [
  {
    type: 'text',
    name: 'username',
    message: 'What is your GitHub username?'
  },
  {
    type: 'number',
    name: 'age',
    message: 'How old are you?'
  },
  {
    type: 'text',
    name: 'about',
    message: 'Tell something about yourself',
    initial: 'Why should I?'
  }
];

let response = await prompts(questions);

// => response => { username, age, about }
```

## node-images

Node.js 轻量级跨平台图像编解码库

```js
var images = require("images");

images("input.jpg")                     //Load image from file 
  //加载图像文件
  .size(400)                          //Geometric scaling the image to 400 pixels width
  //等比缩放图像到400像素宽
  .draw(images("logo.png"), 10, 10)   //Drawn logo at coordinates (10,10)
  //在(10,10)处绘制Logo
  .save("output.jpg", {               //Save the image to a file, with the quality of 50
    quality: 50                    //保存图片到文件,图片质量为50
  });
```

## 动画库

1. react-motion - 解决动画问题的方案之一。
2. react-spring - 基于 Spring 物理的 React 动画库。
3. ant-motion - Ant 设计的 Animate 规范和组件。
4. react-move - 优雅的，基于数据驱动的动画。
5. react-flight - React 构建动画的最佳方法。
6. react-flip-move - 使用 FLIP 技术更改 DOM（例如列表重新排序），从而轻松实现 动画 效果。
7. react-burger-menu - 位于屏幕之外的侧边栏组件，它使用 CSS 过渡共话和 SVG 路径动画实现。
8. animated - 用于 React 和 React Native 的声明性动画库。
9. react-tween-state - React 动画。
10. react-animations - 内联样式库的动画集合。
Javascript库：
1. GSAP - 适用于现代网络的超高性能、专业级动画。
2. Anime.js - Anime.js（/ˈæn.ə.meɪ/）是一个轻量级 JavaScript 动画库，具有简单但功能强大的API。 它适用于 CSS 、SVG、DOM 属性和 JavaScript 对象。
3. Popmotion - 用于灵活简单的用户界面的动画库。
4. vivus - 在 SVG 上制作绘图动画的 JavaScript 库。
5. svg.js - 用于操作动画 SVG 的轻量级库。
6. velocity - Velocity 是一个动画引擎，与 jQuery 的 $.animate() 具有相同的 API 。
7. wow - 滚动时显示动画，Animate.css 的朋友。
8. dynamic.js - 使用这个 Javascript 库创建基于物理的动画。
9. granim.js - 使用这个小的 JavaScript 库创建流畅的、交互式的渐变动画。
10. kute.js - KUTE.js 是一个原生的 JavaScript 动画引擎，具有出色的代码质量和性能。
11. TweenJs - 一个简单但功能强大的 Javascript 动画库。CreateJS 库的一部分。
12. moveTo - 一个不依赖任何其它库的轻量级的 javascript 库，用于创建滚动动画。
